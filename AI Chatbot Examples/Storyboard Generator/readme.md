# Storyboard Generator

I keep this example in my SEG3125 course collection as a reference for conversational storytelling and structured generation.

## What the example demonstrates

- Chat about storyboarding and narrative ideas.
- Turn an entered scenario into a six-scene storyboard.
- Request a table describing the scenes, visual information, and their purpose.
- Present chat and storyboard generation in separate Gradio tabs.

[Original hosted demo on Rahatara's Hugging Face profile](https://huggingface.co/spaces/Rahatara/StoryboardGenerator)

This is a course reference example, distinct from my own linked projects. Generated storyboards are drafts for creative exploration.
